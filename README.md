# Archive of ISMIR Paper Templates
LaTeX and Word templates for ISMIR conferences by year. 
This repository has been archived as we have moved to release based versioning instead of folder based. 

Please do not use the templates here, this repo will no longer be maintained. Please use the templates from:
- https://github.com/ismir/paper_templates_ISMIR

TISMIR templates live in their own repositories:
- https://github.com/ismir/paper_templates_TISMIR_new (original layout)
- https://github.com/ismir/paper_templates_TISMIR_old (lightweight)
